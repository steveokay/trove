# ADR 0019 — UI stack and design direction

- Status: accepted (2026-09-01)
- Task: D-005

## Context

Constraints from §10: static assets embeddable via `go:embed`; builds offline in
CI; says something useful with JS disabled; WCAG AA accessible; dark mode; dense
operator-tool design; renders from the effective-permissions endpoint; strictly a
client of the admin API (ADR 0015).

## Decision

### Stack

- **Svelte 5 + Vite, TypeScript, built as a static SPA** (no SvelteKit, no SSR —
  there is no Node at runtime; the Go binary serves `web/dist` via `go:embed`).
- Runtime dependency budget is deliberately near-zero: Svelte compiles away; no
  component framework, no CSS framework, no client router library (a ~50-line
  hash-based router — the server then needs no catch-all rewrite rules), no fetch
  wrapper beyond a typed thin client generated by hand against
  `docs/api/openapi.yaml`. Every added runtime dependency is a reviewed decision.
- **Offline builds**: `pnpm` with a committed lockfile; CI restores the pnpm
  store from cache and runs `pnpm install --offline && pnpm build` — zero network
  at build time. A `make ui-vendor` target can produce a tarball of the store for
  fully air-gapped release builds. Toolchain versions pinned via `packageManager`
  + `.nvmrc`.
- **JS disabled**: the shell HTML contains a `<noscript>` block stating the UI
  requires JavaScript and pointing at the CLI and API docs — the §10 bar
  ("at least far enough to say so"), met honestly rather than pretending a
  read-only SSR mode exists.
- Testing: Vitest for components/logic; Playwright smoke suite (login, browse,
  explain-permissions, policy dry-run) run against a real `trove serve` binary in
  CI — the UI's integration test is also an API-contract test. The Go coverage
  gate excludes `web/` (it has its own coverage report).

### Design direction

- **Dense, information-first**: tables as the primary surface (tags, CVEs,
  bindings, deliveries) with column sorting, text filtering, and stable
  pagination mapped to the API's cursors. Monospace, single-click-copyable
  digests everywhere. No hero sections, no cards-for-the-sake-of-cards.
- **Navigation**: left sidebar (Repositories, Search, Vulnerabilities, Policies,
  Webhooks, Identity & Access, Audit, System), driven by the
  effective-permissions endpoint — sections the subject cannot use are absent
  (ergonomics only; the server enforces regardless, §5).
- **Theming**: CSS custom properties, `prefers-color-scheme` respected with a
  manual override persisted in `localStorage`; dark is the reference theme,
  light is derived. All colors defined as tokens; contrast checked to WCAG AA in
  CI via an axe pass in the Playwright suite.
- **Accessibility**: real `<table>`, `<nav>`, `<form>` semantics; visible focus
  rings; keyboard reachability asserted in the smoke suite; no
  hover-only affordances.
- Empty states teach: an empty repository list links the `docker login` /
  `docker push` quickstart with the instance's real hostname substituted.

## Rejected alternatives

- **React + a component library** — larger runtime, dependency churn, and the
  component libraries fight the dense-table aesthetic; nothing here needs
  React's ecosystem.
- **htmx / Go templates (server-rendered)** — best JS-disabled story, but couples
  rendering to server internals, and §10's "the API is the contract; the UI is
  one client" is the controlling constraint: a template layer becomes a private
  second API by stealth.
- **SvelteKit** — brings SSR/adapter machinery we explicitly don't run; plain
  Vite keeps the build a pure static-asset function.
- **No-build vanilla JS** — tempting for offline purity, but forfeits types and
  componentization the admin surfaces (policy editor, binding editor) genuinely
  need; the pnpm-store cache achieves offline anyway.

## Consequences

- `web/` owns `package.json`, `src/`, `dist/` (gitignored); `web/embed.go`
  embeds `dist` and the Makefile orders `ui-build` before `go build`. Release
  artifacts always contain a freshly built UI; a `make dev` proxy setup gives
  hot reload against a running trove.
- U-001 is unblocked; the U-002 effective-permissions endpoint lands in the API
  first (ADR 0015 rule).
- CLAUDE.md §10 gets the stack recorded, per its own instruction.
